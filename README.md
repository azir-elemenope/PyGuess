# PyGuess (Number-Guessing-Game)
A Python number-guessing game based on logic, deduction, and user-provided clues.

# About
A project for Math 153, created as part of my coursework to apply Python programming, mathematical concepts, and problem-solving.

PyGuess challenges the program to guess a number chosen by the player. Instead of simply making random guesses, Python narrows down the possible numbers on the player's answers to a series of questions.

The game explores different number properties, including primes, even, and odd numbers. As well as divisibility, perfect squares and cubes, digit properties, and higher or lower comparisons.

# Features
- Interactive yes/no questions
- Prime and non-prime number filtering
- Even and odd number filtering
- Divisibility checks
- Perfect square and cube checks
- Digit-based filtering
- Number of digits filtering
- Higher or lower dynamic guessing
- Input validation
- Interactive text-based interface
